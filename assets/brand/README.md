# Reeve brand assets

The mark is the **tally r**: a tally stick (the reeve's record, notched and split so both sides hold
the same account) cut into a lowercase r. The long half is the stem and carries the notches; the
short half is the shoulder. The **seal** is the same r pressed into wax.

| File | What | Where it's used |
|---|---|---|
| `reeve-mark.svg` | the tally r, `currentColor` | the source of the mark; `web/src/lib/components/Logo.svelte` inlines the same path |
| `reeve-mark-16.svg` | the r redrawn for 16px (two notches, snapped to whole pixels) | the 16px favicon |
| `reeve-seal.svg` | the wax seal, `currentColor`, ring and r cut out | the source of the seal (generated by `make-seal.py`) |
| `reeve-seal-512.png` | the seal in the light colour, transparent | the repository README, the social card |
| `social-card.html` | the 1280×640 card: the seal, the name and the tagline | the source of `reeve-social.png` |
| `reeve-social.png` | the card, rendered | the repository's social preview (Settings → General → Social preview, uploaded by hand) |

The web client's copies are `web/static/favicon.svg`, `favicon.ico` and `apple-touch-icon.png`.

## Regenerating the bitmaps

Needs `rsvg-convert` (librsvg) and ImageMagick 7. Run from the repository root:

```sh
python3 assets/brand/make-seal.py
t=$(mktemp -d)
sed 's/currentColor/#765f93/' assets/brand/reeve-seal.svg > "$t/seal.svg"
sed 's/currentColor/#765f93/' assets/brand/reeve-mark-16.svg > "$t/m16.svg"
rsvg-convert -w 512 -h 512 "$t/seal.svg" -o assets/brand/reeve-seal-512.png
rsvg-convert -w 180 -h 180 -b '#faf4ed' "$t/seal.svg" -o web/static/apple-touch-icon.png
rsvg-convert -w 16 -h 16 "$t/m16.svg" -o "$t/16.png"
rsvg-convert -w 32 -h 32 web/static/favicon.svg -o "$t/32.png"
magick "$t/16.png" "$t/32.png" web/static/favicon.ico
rm -r "$t"
```

The touch icon has an opaque background because iOS shows transparency as black.

The social card is rendered with Playwright's Chromium, so it uses the web client's Instrument Sans (run `mise run web`
first so `web/node_modules` exists). Run from the repository root:

```sh
(cd web && npx playwright screenshot --viewport-size=1280,640 --wait-for-timeout=500 \
  "file://$PWD/../assets/brand/social-card.html" ../assets/brand/reeve-social.png)
```
